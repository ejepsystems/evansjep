# Mobile presentation standards

Updated 20 October 2026. Preserve Times-style serif, obsidian/ivory themes, supplied biography and contact details.

## Geometry

Support 320px upward. Fluid gutter 20–28px; 64px mobile header; 44px touch targets and 48px primary action. Header background spans the viewport. Content-driven height avoids assumptions about browser chrome, landscape screens and text scaling.

## First screen

Use the two deliberate headline lines “Builder.” and “Steward.”, 44–52px. Purpose statement 20–22px; short supporting text 16px. No giant decorative panel. Intro starts 36–44px below the header. Actions stack at 360px and below. No horizontal page scrolling intended.

## Navigation

Compact 304px maximum panel with two columns, no decorative numbering. Dynamic viewport max-height and contained scrolling support short displays. Focus cycling, Escape restoration, outside-tap dismissal, background inert and reduced motion are supported.

## Verification limits

Build, link, markup and interaction checks are available. Real rendered viewport, operating-system font fallback and text enlargement need browser/device review; source checks are not represented as visual certification.

## Monochrome refinement

Brown/champagne removed. Black #111210 is the light-theme accent; ivory #F2EEE5 is the dark-theme accent. Stylesheet consolidated into component definitions and two responsive ranges. Scroll-triggered content animation removed to preserve reading stability. Menu motion alone remains, respecting reduced-motion preferences. Keyboard focus, Escape, outside dismissal, breakpoint reset and stored theme checked.
